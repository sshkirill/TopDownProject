# TopDownProject

A small top-down gameplay project built with Unreal Engine 5.

## Overview

This project focuses on building modular and maintainable gameplay
systems rather than a large number of gameplay features.

## Current Features

- Command-based character movement
- Modular interaction system
- Interactive world objects
- Component-based gameplay architecture

## Planned Features

- Inventory system
- Quest system
- Save / Load system
- World state and progression

## Technologies

- Unreal Engine 5
- C++
- Blueprints
- Git
- Git LFS
